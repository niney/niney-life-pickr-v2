## Purpose [coverage: high — 8 sources]

`@repo/utils` — 순수 함수 모음. FE/BE 모두에서 import 가능한 사이드 이펙트 없는 헬퍼만 모아 둔다. 외부 npm 의존이 0개(devDependencies 는 `@repo/config`·typescript·vitest 뿐)고 어떤 런타임(Node, 브라우저, RN/Hermes)에서도 실행된다. CLAUDE.md의 의존 그래프상 leaf 노드 — `shared`, 모든 앱이 여기로 들어올 수 있지만 utils는 어디로도 의존하지 않는다(`@repo/api-contract` 도 utils 를 import 하지 않는다 — 두 패키지는 서로 독립이고, 겹치는 enum 키 목록은 "같은 순서" 계약으로만 묶인다).

네 층이 공존한다. (a) **도메인 코드표·정규화** — 대기 등급 구간(`airQuality`), 기상청 격자·발표 시각·코드표(`weather`·`weatherRegions`), 일상지도 코드표·집계 셀(`lifeMap`), 집값 코드표·가격 포맷·연월(`housing`), 음식 분류 축(`foodTaxonomy`), 끼니·양·날짜 키(`mealSlot`), 영양 합계(`mealNutrition`), 리뷰 방문일(`reviewDate`), 대중교통(`busArrival`·`subwayLine`·`subwayTimetable`·`subwayCongestion`) — **friendly 의 적재·정규화·캐시 TTL 계산과 웹·앱 표시가 같은 함수를 호출**하는 것이 이 층의 존재 이유. (b) **지도 마커 SVG** — `markerFrame.ts` 가 식당·버스·지하철·대기·일상지도(+집값 빈 단지 핀) 공용 골격을 대고 각 도메인 모듈(`restaurantCategory`·`busMarker`·`subwayMarker`·`airMarker`·`lifeMapMarker`·`housingMarker`)이 색/아이콘만 채운다; `vehiclePill`·`routePath`·`subwayPosition` 은 차량 위치/이동 기하. (c) **결정적 선택 엔진(2026-09 신설)** — 타로(`tarotCards`·`tarot`·`tarotFlow`·`tarotMenu`), 사주(C)(`sajuCalendar`·`saju`·`sajuText`·`sajuDaily`·`sajuInsights`·`sajuDayPillar`·`sajuMatch`·`sajuDatePick`·`sajuFood`·`sajuFlow`·`sajuImages` + 생성물 `sajuAstroTable`), 사주(G) 상징 표(`saju-g`·`saju-g-stories`) — **후보·점수·명식·흐름 상태는 코드가 결정적으로 만들고 LLM 은 그 위에 문장만 쓴다**. 서버는 같은 함수로 검증(`validateDrawnCards`)·프롬프트 사실 목록(`sajuFactLines`)·캐시 키(`chartSignature`)를 만들고, 웹은 결과가 오기 전에 같은 후보를 미리 보여 주며 3D 무대·2D 뷰가 같은 리듀서 상태를 그린다. 세부 도메인은 [tarot](tarot.md)·[saju-c](saju-c.md)·[saju-g](saju-g.md)·[housing](housing.md). (d) **표현 헬퍼** — `reviewThumbnailUrl`/`isThumbnailProxyable`(friendly 미디어 프록시 URL·허용 호스트 판정), `formatWonPrice`, 대중교통 포맷터(`format.ts`), `dateLabel`, `aiModel`(모델 계열/용도 8종 추천/think 옵션), `pickRandom`/`shuffle`(Pick 추첨).

**모듈 간 내부 의존(전부 utils 안에서 닫힘)** — `markerFrame.ts`(공용 핀/원 골격) ← `restaurantCategory`·`busMarker`·`subwayMarker`·`airMarker`·`lifeMapMarker`·`housingMarker`(빈 단지 선택 핀만; 가격 배지·셀은 자체 알약 규격)(도메인 아이콘/색). 프레임을 한 곳에 두어 여섯 도메인 마커가 같은 anchor·라벨 offset·축소 스케일 규격을 강제로 공유한다. `airMarker` → `airQuality`(등급 타입), `lifeMapMarker` → `lifeMap`(그룹/레이어/버킷), `housingMarker` → `housing`(`HousingDealType`), `weatherRegions` → `geo`(`haversineM`), `dateLabel` → `weather`(`kmaTodayIsoDate` 재수출), `routePath`·`weather` → `geo`(`LatLng`). 별도로 `vehiclePill.ts`(차량 알약/방향)는 markerFrame 을 안 쓰는 자체 SVG 골격이지만 `busMarker`·`subwayMarker` 두 도메인 차량이 공유하는 코어라 한 겹 더 추출. `routePath.ts`(버스 형상 투영)·`subwayPosition.ts`(전철 역간 보간)는 마커가 아니라 이동 위치 계산 — 버스는 도로 폴리라인 추종, 전철은 GPS 없이 역 순서 기반이라 코어가 갈린다.
