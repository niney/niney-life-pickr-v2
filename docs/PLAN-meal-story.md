# 건강식단 스토리(PLAN)

주제 하나(나트륨 줄이기 …)를 장면 여러 장으로 넘겨 보는 손수 만든 콘텐츠 코너. 만드는 절차는
[meal-story-authoring.md](meal-story-authoring.md).

## 결정(2026-11-09, 사용자)

| 물음 | 결정 |
|---|---|
| 어디에 | **서비스 안 화면**(SNS 영상 아님) — 장면 틀 + 원고. 영상(Remotion 등)은 나중에 같은 원고로 따로 만들 수 있다 |
| 누구에게 | **누구나**(로그인 없이) — 공유 링크·카카오톡 미리보기. 내 데이터 장면(내 평균)·[이 레시피로 기록]만 로그인 |
| 첫 편 | 나트륨 줄이기 + 토마토 스파게티, **면 바꾸기는 같은 편의 덤 장면** |
| 영양 목표 | **하지 않는다** — 영양 탭 판정('많음'·'부족')이 스토리를 고른다 |

## 설계

- **원고 = 서버 파일** `apps/friendly/content/meal-stories/<slug>/story.json`(git). 공유 미리보기(OG)를 서버가 만들어야 해서
  웹(`public/`)이 아니라 friendly 가 읽는다. DB·어드민 업로드는 편이 쌓여 배포 없이 올리고 싶어질 때.
- **숫자는 가리키기만** — 섭취기준(KDRI, 영양 탭과 같은 표)·식품 100g당 값(식약처 원재료성·가공식품 표준데이터 코드 →
  `build:meal-stories` 가 `foods.json` 으로)·레시피 합계·내 기록. 서버가 계산해 응답에 넣고, 출처를 값마다 단다. 시판 제품은
  여러 제품의 중앙값.
- **장면 틀 8종**(표지·큰 숫자·막대 비교·목록·재료·만드는 법·영양정보·마무리) — 편마다 화면 코드를 새로 짜지 않는다.
- **움직임은 CSS 만** — 숫자 굴러가기(자리마다 0~9 띠 두 바퀴), 막대 자라기, 글 차례로 떠오르기, 사진 켄 번스. 장면은 손으로
  넘기고(누르기·밀기·키), '동작 줄이기'면 끝 상태만. 새 라이브러리 없음.
- **초안은 관리자만**(목록·한 편·기록 연결). 사진은 인증 없이(`<img>`), 초안 사진도 — 글은 새지 않는다.
- **[이 레시피로 기록]** — 식단 기록은 카탈로그 행으로 영양을 계산하므로, 레시피를 카탈로그 음식(`manual`,
  `meal-story:<slug>`)으로 맞추고 그 음식으로 새 기록 draft 를 채운다. 스토리 숫자 = 기록 숫자. 이름이 겹치면 '(건강식단)'.
- **입구** — 사이트 메뉴·식단 사이드 메뉴 '건강식단', 식단 홈 새 이야기 한 줄(게시 30일 안), 영양 탭 '많음'·'부족' 줄의
  '줄이는 법 보기'·'채우는 법 보기'(같은 영양소·방향의 게시본).
- **점검** — `check:meal-stories`(형식·가리킴·효능 단정 말투·글에 박힌 영양 값·게시 조건·사진 크기·foods.json 과 원본 대조·
  계산된 숫자와 출처 목록)와 내용 테스트(`meal-story.content.test.ts`, 같은 규칙).

## 한 일 — 2026-11-09

1. **토마토 영양값 바로잡기**(선행) — 운영 '토마토'가 '연두부 토마토'의 1인분(155g 110kcal, 100g당 71kcal)을 빌려 와 있었다.
   원인 둘: 병합이 빈 칸만 채워 나중에 온 원재료 값이 빌린 값을 못 덮었고, 빌려 오기가 100g당 직접 값이 있는 행(원재료 '자두'
   ← 요리 '상큼하자두')까지 대상으로 삼았다. 빌린 영양은 직접 값이 오면 통째로 물러나고, 100g당 직접 값이 있는 행은 빌려 오지
   않는다. 로컬 운영 사본 `load:food-catalog --source=raw` 로 2행 갱신(토마토 100g당 21kcal). 운영은 배포 뒤 같은 명령.
2. **스토리 틀** — 계약(`@repo/api-contract` MealStory·라우트), friendly `meal-story` 모듈(원고 형식·해석·파일 저장소·API 4개·
   공유 미리보기·레시피 음식 맞추기), 스크립트 `build:meal-stories`(foods.json·사진·`--find` 식품코드 찾기)·`check:meal-stories`,
