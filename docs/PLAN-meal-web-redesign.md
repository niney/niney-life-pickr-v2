# 웹 식단 리뉴얼 — 하위 사이트 (2026-11-08~)

식단을 Life Pickr 안의 '주 사이트'처럼 만든다. 다른 메뉴(공통 shadcn 중립 스타일)와 별개의 모습, 왼쪽 사이드 메뉴, 간단명료한
식단 홈 대시보드, 데스크톱 폭 활용과 모바일 최적화. 앱(Expo)은 웹이 끝난 다음 단계([PLAN-mobile-meal.md](PLAN-mobile-meal.md)).

## 구조

- `App.tsx` — `/meal/*` 를 `MealApp` 한 덩어리로 늦게 부른다(어드민과 같은 방식, 로그인 필수). `/me/meals/*` 는 `LegacyMealRedirect`.
- `routes/meal/MealApp.tsx` — 셸 아래 경로별 화면. 홈은 바로, 나머지는 들어갈 때 부른다.
- `MealShell.tsx` — 사이드 메뉴·상단바·하단 탭(입력·상세·수정에서는 숨김)·서랍·원티드 산스 로드. 본문 `max-w-[1240px]` 왼쪽 정렬.
- `mealTheme.css` — 색·모서리 토큰은 `html:has(.meal-app)` 에서 shadcn 변수를 다시 정한다(사진 크게 보기처럼 body 로 빼서 그리는 창까지).
  tailwind.css 의 `:root`/`.dark` 가 레이어 밖이라 이것도 레이어 밖 + 더 높은 명시도. 부품 클래스는 `@layer components`
  (레이어 밖이면 `md:hidden` 같은 유틸리티를 이겨 모바일 바가 데스크톱에 뜬다 — 시안에서 겪음).
- `mealPaths.ts`(경로·`legacyMealPath`·`mealPanelKindOf`), `MealPageHeader.tsx`(제목 + 휴대폰 묶음 전환), `MealHomePage.tsx`,
  `mealDraftStart.ts`(홈의 빈 끼니 칸·자주 먹은 음식 → 그 끼니·음식으로 새 기록 시작, 다른 끼니면 그 끼니의 보통 시각 / 새로 쓰기 /
  고친 내용 판정 `isMealDraftChanged`).
- 패널(3단계) — `mealPanel.ts`: 데스크톱(1024px~)에서 상세·수정·새 기록을 열 때 뒤 화면 위치를 `history.state.mealBackground`
  에 싣는다(react-router 7 의 `mask` 는 데이터 라우터 전용이라 선언형 예제 방식). `MealApp` 은 배경 위치로 셸을 그리고 진짜 위치로
  패널 경로를 따로 그린다(수정·새 기록이면 셸을 `inert`). 이미 패널이 떠 있으면 같은 배경을 물려주고(패널 하나에 쌓기), 옆 목록·↑↓ 로
  바꿀 때는 기록 한 칸으로 바꿔(replace) 뒤로 = 닫기. `MealLink`(기록 줄·기록하기 단추)·`useMealOpen`·`useMealLeave` 가 이 값을
  만든다. 주소로 바로 열면 배경이 없어 한 화면. 스크롤은 `MealApp` 이 맞춘다(새 화면 맨 위·뒤로 보던 자리·패널 열고 닫을 땐 그대로,
  브라우저 자동 복원은 끔).
- `MealSurface.tsx` — 상세·입력의 틀. 패널이면 머리(제목·↑↓·✕)·몸통(@container)·발(동작 줄), Esc·바깥 누르기(모달)·포커스
  들여보내기/돌려주기(기록 줄 `data-meal-entry`)·뒤 스크롤 잠금(모달). 화면이면 휴대폰은 자체 상단바(←) + 아래 고정 동작 줄,
  태블릿 이상은 큰 제목 + 화면 아래 붙는 동작 줄. 안쪽 두 단은 컨테이너 쿼리(48rem)라 640px 패널은 한 단, 880px 패널·데스크톱은 두 단.
  확인 창은 `overlay` 로 @container 밖에 그린다(컨테이너가 fixed 자식의 기준 상자가 될 수 있다).
- 좁은 화면 전환 — 상세·입력으로 들어갈 때 `document.startViewTransition`(오른쪽에서 밀려 들어옴), ← 로 나갈 때 반대. BrowserRouter 가
  위치 바꿈을 startTransition 으로 그려 flushSync 가 안 들어서, 새 위치가 그려졌다는 `MealApp` 의 레이아웃 효과까지 기다린다(최대 0.9초).
  브라우저 뒤로(제스처)는 브라우저에 맡긴다. 식단에 들어오면 한가할 때 상세·입력 조각을 미리 받는다.
- `MealFoodSheet.tsx` — 휴대폰(767px 이하) 음식 찾기. 검색칸·완료는 위(키보드에 가리지 않게), 높이는 visualViewport 에 맞춘다.
  치기 전: 이 끼니에 자주 먹은 음식 + 최근 끼니 통째로. 치는 중: '그대로 넣기' → 내 기록(`/meals/items/frequent?q=`, 1자부터·최근 1년)
  → 음식 목록(`/food/search`, 2자부터 — 내가 먹은 음식 먼저·1인분 열량). 줄을 누르면 넣고 다시 누르면 뺀다(빠른 추가 칩과 같은
  `toggleQuickItem`), 이름 있는 줄은 그 줄만 바꾸고 닫는다. 김치·나물은 반찬으로(`MEAL_SIDE_DEFAULT_DISH_TYPES`, 서버 1인분 열량도 같은 규칙).
