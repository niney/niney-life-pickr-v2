# 사주(G) 이야기 카드 — 2026-09-07

사용자가 승인한 1차 추천안: 내 일주 이야기, 생활 사용설명서, 십성 이야기 카드. 개인 원국(`/saju-g`의 나의 사주)과 보관 결과에 제공한다.

## 구현

- **내 일주 이야기**: 확정된 일간·일지의 오행 상징으로 대표 장면을 만든다. 기존 SVG 상징, 두 오행의 색, 궤도·인장·빛을 사용한다. 펼치면 설명·질문·명식 근거가 나타나고 해당 오행을 강조한다. 풍경은 전통의 고정된 60일주 해설이 아닌 제품의 상징 창작으로 구분한다.
- **생활 사용설명서**: 첫 만남, 일이 몰릴 때, 갈등 대화의 세 장면. 각각 풀이·작은 행동·질문·근거를 제공한다. 원국 요청 한 번에 세 장면을 생성해 기존 캐시·명시적 보관에 함께 넣으며, 장면 전환은 추가 AI 호출을 만들지 않는다.
- **십성 이야기**: 확정된 천간·지장간에 실제로 등장한 십성만 카드로 묶어 모든 위치를 표시한다. 일간 자신은 비견 위치로 집계하지 않는다. 등장 횟수나 부재를 능력의 강약으로 해석하지 않는다.
- 명식이 먼저 도착하면 정적 카드와 기본 생활 안내를 표시한다. AI가 도착해도 선택한 장면을 유지한다. 구버전 보관 결과에 새 필드가 없으면 기본 안내를 표시하고 AI 문장으로 표시하지 않는다.
- 일주·일간 미확정이면 대표 카드·십성 관계를 추정하지 않는다. 생활 장면은 `scope` 근거의 일반 질문만 허용한다.
- 390px/1440px 반응형, HTML details의 키보드 조작, 선택 버튼의 `aria-pressed`/`aria-controls`, 모션 줄이기를 지원한다.

## 계약·모델·데이터

`SajuGLifeScene`은 api-contract의 Zod 계약이다. `SajuGReport.lifeScenes`는 이전 보관·궁합·기간 풀이 호환을 위해 optional이지만, v4 원국 AI 출력에서는 순서가 고정된 세 장면이 필수다. 장면의 근거 ID, 본문 복제, 잘못된 일간·간지·점수·질문 재인용도 검사한다. 일간 미확정 장면에 `scope` 외 근거가 있으면 거절한다. 서로 다른 장면에 공백 제외 25자 이상의 같은 설명 문장이 반복되거나 원국에서 좋은 시기·유리한 날을 판정하는 표현도 재시도한다. 이 검사는 모든 의미 중복·기간 예측을 판별하는 완전한 자연어 검증기는 아니다.

`SAJU_G_PROMPT_VERSION=4`, Kimi K3를 유지한다. 원국 최대 출력은 5,000토큰, 오늘·올해는 기존 3,500토큰이다. 전체 60초·최대 두 호출과 성공 AI만 캐시하는 정책을 유지한다. 초기 v4 실험에서 미확정 일간을 연주·월주로 대체한 생활 해석을 발견해 검증과 `lifeSceneGuide`를 보강했다.

DB migration과 신규 API 경로는 없다. 새 장면은 기존 JSON snapshot에 함께 보관한다. 원본 생년월일·시각·계정은 모델에 추가 전송하지 않으며, 공개 공유 필드에 생활 풀이·일주 카드·십성 위치를 추가하지 않는다. 사주(C)는 수정하지 않았다.

순수 콘텐츠는 `packages/utils/src/saju-g-stories.ts`, 플랫폼 UI는 `apps/web/src/components/saju-g/SajuGDiscoveries.tsx`에 분리했다. 평가 CLI는 `--output`과 `--case=1~12`를 지원해 기존 평가를 덮어쓰지 않고 문제 사례만 재검증할 수 있다.
